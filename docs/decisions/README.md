# Architecture decision records

ADRs capture durable decisions and their tradeoffs. Use the next sequential number and this structure:

```markdown
# NNNN — Decision title

Status: Proposed | Accepted | Superseded by NNNN

## Context

What forces and constraints require a decision?

## Decision

What are we choosing?

## Consequences

What becomes easier, harder, or deliberately deferred?
```

Accepted records are historical. Add a new ADR to supersede one instead of silently rewriting it.
