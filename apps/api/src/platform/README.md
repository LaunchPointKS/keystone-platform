# Platform core

Planned shared capabilities:

- Identity and internal `Principal`
- Organizations, memberships, invitations, and RBAC
- Files and private object-storage access
- Activity events and realtime publication
- Notification intents and delivery
- Offline sync cursors and change feeds
- Transactional outbox and job infrastructure
- Observability, request context, and structured errors

Platform core must not import a product module.
